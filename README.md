# Floating Ro Translate

A Windows desktop translator that keeps a floating overlay on top of your screen and translates Romanian and Ukrainian text into English.

This project reads text under the cursor using Windows OCR and UI Automation when available, then translates it with Google Translate. It is designed for quick workstation use, especially when reading text from browser tabs, chat apps, documents, or other Windows applications.

Built in Python with help from Claude.

## Features

- Hover over text on screen to translate Romanian or Ukrainian into English
- Always-on-top floating translation window
- Optional highlighted-selection translation
- Reply panel for translating English back into Romanian or Ukrainian
- Uses Windows built-in OCR and UI Automation for better text extraction
- Works with Romanian and Ukrainian language setups on Windows 10/11

## Supported languages

- Romanian -> English
- Ukrainian -> English
- English -> Romanian/Ukrainian via reply panel

## Requirements

- Windows 10 or 11
- Python 3.10+
- Microsoft language support for Romanian and/or Ukrainian OCR packs
- Internet access for Google Translate requests

## Quick start

### Option 1: Use the included batch launcher

```bat
run.bat
```

### Option 2: Manual setup

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python ro_hover_translate.py
```

## Build executable

```bat
build.bat
```

This will create a packaged executable in the `dist` folder.

## Notes

- The app is intentionally designed for Windows and depends on WinRT, UI Automation, and Windows OCR features.
- If Windows OCR does not have a language pack installed, the app will fall back to alternative behavior and may show a warning.
- Google Translate is used as the translation backend; internet access is required.

## Troubleshooting

### OCR language not available

Install the required language support in Windows:

- Settings > Time & Language > Language & region
- Add Romanian or Ukrainian
- Ensure the OCR feature is installed for the selected language

### App does not start

Check that dependencies are installed correctly:

```bat
.venv\Scripts\pip install -r requirements.txt
```

### Translation is slow or rate-limited

Google Translate may occasionally rate-limit requests. The app includes backoff logic and retries automatically.
